# Restitution des accents du corpus départemental — table mot → mot.
#
# Pourquoi elle existe : le brief n'exigeait l'ASCII que sur les champs COURTS (§ 193 :
# « libelle et resume peuvent en porter »), mais le rédacteur l'a appliqué à toute la
# prose. Résultat mesuré le 10/08/2026 : sur 730 champs de texte affiché, 63 seulement
# portent un accent. Les 84 pages départementales publiaient « epandages », « regimes
# distincts », « Bouches-du-Rhone ».
#
# ⚠️ CE QUI N'EST PAS ICI, ET POURQUOI. Une table mot → mot est aveugle au contexte. Tout
# mot dont la forme SANS accent est elle-même un mot français valide en est donc exclu :
#   · les participes passés homographes d'un présent — `concentre` est « il concentre »
#     autant que « concentré » ; idem ajoute, applique, calcule, classe, corrige, situe…
#   · les mots courts — `a`/`à`, `ou`/`où`, `des`/`dès`, `du`/`dû`, `sur`/`sûr`, `la`/`là` ;
#   · `cote` (côte, côté, cote), `foret` (forêt, foret), `pres` (près, prés), `mur`, `tache`.
# Les traiter demanderait de relire chaque phrase — c'est un second temps, pas celui-ci.
#
# Le contrôle qui rend cette table sûre : `accentuer_departements.py` vérifie que chaque
# paire ne diffère QUE par des accents (même texte une fois désaccentué), et que chaque
# champ réécrit est identique à l'original une fois désaccentué. Une entrée fautive ne
# peut donc pas changer un mot, seulement sa graphie.
#
# Format : <sans accent><TAB><avec accent>, un par ligne. Les lignes vides et les # sont ignorées.
